# 📊 PhonePe Transaction Analysis Dashboard | Power BI

## 📌 Project Overview

The **PhonePe Transaction Analysis Dashboard** is an interactive data analytics project developed using Microsoft Power BI. The main objective of this project is to analyze UPI transactions, understand customer behaviour, track transaction performance, and identify important business trends.

This dashboard provides a comprehensive overview of transaction activities through interactive KPIs, charts, graphs, and a Month Slicer. It helps analyze transaction values, payment services, customer demographics, and weekday versus weekend transaction patterns.

The project analyzes **30K transactions and 30K users**, transforming raw data into meaningful business insights.

## 🎯 Project Objectives

- Analyze total transaction value and transaction volume.
- Monitor successful transaction percentages.
- Understand monthly transaction performance.
- Identify high-performing payment services.
- Analyze customer distribution by age groups.
- Compare weekday and weekend transaction activities.
- Create an interactive dashboard using Month Slicers.
- Generate business insights to support data-driven decisions.

## 📅 Monthly Transaction Analysis

### 1. Total Transaction Value by Month
- Displays transaction values from January to December.
- March records the highest transaction value.
- April shows a significant decline.
- Transaction value improves from May onwards.
- Helps identify monthly transaction trends.

### 2. Total Transactions by Month
- Displays monthly transaction volumes.
- Transaction counts remain approximately between 2.4K and 2.6K.
- March and July show relatively higher transaction volumes.
- Helps compare monthly transaction performance.

## 💳 Service-Wise Transaction Analysis

The dashboard compares five major payment services:

| Payment Service | Performance |
|---|---|
| Recharge | Highest |
| Bills | Second Highest |
| Money Transfer | Third Highest |
| Insurance | Fourth Highest |
| Loans | Lowest |

**Key Insights:**
- Recharge contributes the highest transaction value.
- Bills represent the second-highest service.
- Money Transfer is another important payment category.
- Insurance and Loans contribute comparatively lower transaction values.

## 📆 Weekday vs Weekend Analysis

The dashboard compares transaction activities on weekdays and weekends.

| Day Type | Transactions | Percentage |
|---|---:|---:|
| Weekday | 21K | 71.52% |
| Weekend | 9K | 28.48% |
| Total | 30K | 100% |

**Key Insights:**
- 71.52% of transactions happen during weekdays.
- 28.48% of transactions happen during weekends.
- Weekday transaction activity is significantly higher.

## 🎛️ Interactive Month Slicer

An interactive Month Slicer is implemented on the left side of the dashboard.

**Features:**
- Month selection from January to December.
- Dynamic filtering of transaction data.
- Month-wise performance analysis.
- Interactive KPI and chart updates.
- Easy comparison of monthly transaction trends.

Users can select any month to explore the corresponding transaction performance across connected dashboard visuals.
